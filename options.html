UMBRA SETTINGS

Guides and setup for Umbra features.

Video transcription

OpenRouter API key

The Transcript button on Skool and Whop videos transcribes the audio in the browser with Whisper (openai/whisper-large-v3-turbo) through OpenRouter, then saves a .txt and a .srt file. Create a key at openrouter.ai/keys and paste it below. It is stored in Chrome local storage and never leaves your browser except for OpenRouter requests.

Video download setup

How it works

  1. Umbra adds Download and Transcript buttons to supported videos on Skool and Whop.
  2. Click Download. If Umbra cannot detect the stream, play the video once and try again.
  3. Mux streams (Skool and Whop native players), Loom embeds and Wistia embeds download directly as .mp4 — no tools needed.
  4. For YouTube embeds, Umbra shows a yt-dlp command to copy and run in Terminal.

What to install

yt-dlp is only needed for YouTube embeds. FFmpeg and ffprobe are recommended for those (separate video and audio streams must be merged).

Using yt-dlp

Windows — open PowerShell or cmd and paste the command shown in the download modal. If yt-dlp is not found, install it first with winget install yt-dlp or download the .exe from the install link below. The file will be saved in your current directory — usually C:\Users\YourName.

Mac — open Terminal and paste the command. If yt-dlp is not found, install it with brew install yt-dlp (requires Homebrew). The file will be saved in your current directory — usually ~/Downloads if you cd ~/Downloads first, otherwise your home folder.

macOS

Install Homebrew, then install yt-dlp and FFmpeg:

brew install yt-dlp ffmpeg

Linux

Install yt-dlp with Python, then install FFmpeg with your package manager:

python3 -m pip install -U "yt-dlp[default]" sudo apt install ffmpeg
