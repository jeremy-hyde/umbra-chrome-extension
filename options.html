Video download setup

How it works

  1. Umbra adds a Download button to supported videos on Skool and Whop.
  2. Click Download. If Umbra cannot detect the stream, play the video once and try again.
  3. Umbra shows the detected video URL and creates a yt-dlp command.
  4. Copy the command and run it in Terminal. The file is saved in the current Terminal folder.

What to install

yt-dlp is required. FFmpeg and ffprobe are strongly recommended and are needed when separate video and audio streams must be merged.

macOS

Install Homebrew, then install yt-dlp and FFmpeg:

brew install yt-dlp ffmpeg

Linux

Install yt-dlp with Python, then install FFmpeg with your package manager:

python3 -m pip install -U "yt-dlp[default]" sudo apt install ffmpeg
yt-dlp installation FFmpeg downloads

Keys are stored in chrome.storage.local. Umbra sends a key only to OpenRouter for transcription. Local extension storage is persistent, but it is not a protected secret vault.
