Site Effects
old.reddit.com Custom
  • Full dark theme — background, sidebar, header, dropdowns
  • Links recolored teal (#4fbdba)
  • Upvote/downvote arrows use orange and purple accents
  • Code blocks use dark background with orange text
  • Inputs styled with dark fill and light text
github.com Enhanced
  • Invert + hue-rotate filter for dark mode (images/videos re-inverted)
  • Issue content area is wider (max-width 1600px, always on)
  • Issue metadata sidebar narrowed to 240px to give more room to comments
  • PR conversation content area is wider (max-width 1200px, always on)
All other sites Generic
  • CSS invert + hue-rotate(180deg) applied to the whole page
  • Images, videos, iframes, canvas, SVGs are counter-inverted to preserve original colors

Effects only apply when Umbra is toggled on.
